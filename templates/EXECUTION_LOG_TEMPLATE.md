# EXECUTION_LOG

**Entry convention:** every entry that records a task action or a decision must carry inline `T-NNN` and `DR-NNN` references (e.g. "Spawned developer for T-042 per DR-003"), so grepping a single `DR-NNN` id surfaces the decision record, every log entry acting on it, and every task citing it. See `docs/core/DECISIONS.md` for the matching `Informed by:` / `Supersedes:` / `Tasks:` fields on decision records. No graph-rendering tooling — plain grep only.
